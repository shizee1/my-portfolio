# my-portfolio

Личный сайт-портфолио: вёрстка по макету из Figma.

## О проекте

Одностраничный сайт с демонстрацией box model, секцией «обо мне», списком работ и контактами.
Свёрстан на чистом HTML, CSS и JavaScript без сборщиков и фреймворков.

## Стек

- HTML5
- CSS3 (custom properties, grid, flexbox, анимации)
- JavaScript (тема, прогресс прокрутки, reveal-анимации)
